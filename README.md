# ScriptScribe

> **This project is archived.** I built it in college while learning web development, and it has served its purpose. It is no longer maintained, the hosted instance has been taken down, and I won't be accepting issues or pull requests. Feel free to fork it and take it further.

ScriptScribe is a tool designed to facilitate text processing tasks such as optical character recognition (OCR) and text summarization.

## Deploying the webapp

```bash
docker-compose up -d
```
